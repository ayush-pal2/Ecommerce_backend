🛒 E-Commerce Backend API (Django + DRF)

A scalable E-Commerce Backend REST API built using Django and Django Rest Framework.
This project provides APIs for authentication, product management, categories, cart, orders, and role-based access control.

🚀 Features

User Authentication (Register, Login, Logout)

Role-Based Access Control (Admin, Seller, Customer)

Category & SubCategory Management

Product CRUD Operations

Product Search & Filtering

Cart & Wishlist

Order & Checkout System

Pagination & Sorting

Soft Delete Support

Secure APIs with JWT Authentication
